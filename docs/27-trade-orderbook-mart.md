# 27. 체결 × 호가 분 단위 결합 마트 (2026-09-18, 완결)

docs/19 §2-1 순서 3. "누구나 받을 수 없는 플래그"의 재료는 남에게 없는 데이터이고, 우리에게 그것은 호가 이력이다(거래소 미제공). 이 마트는 체결과 호가를 같은 분에 붙여 유동성 관점의 설명 변수를 만든다.

## 1. 설계
- `mart_trade_orderbook_1m` (dbt marts, 증분 delete+insert, 일 단위). 키 (market, minute). 시간 축은 둘 다 거래소 시각.
- 체결: 건수·수량·금액·VWAP·OHLC·매수 비율·분 안 변동폭(bp). 원본은 RMT 라 `FINAL` 로 읽는다.
- 호가: 스냅샷 수·mid·스프레드(bp, 평균·최대)·잔량 불균형(1/5/15호가)·15호가 깊이(수량).
- 결합 파생: **volume_over_depth15** = 그 분 체결 수량 / 15호가 평균 잔량(양쪽 합) — "호가 전체만큼 체결했나"(1 = 전부), close_vs_mid_bp.
- 초기 적재는 mart_from/mart_to 로 하루씩(전체 FINAL 은 메모리 한도). 일일 `dbt run` 이 어제·오늘 2일을 갱신.

## 3. 첫 답: EURC 되튐은 스프레드가 아니라 "깊이 대비 체결량"이었다
docs/14 는 EURC 알림 561건/시간의 원인을 "얇은 호가의 bid/ask 되튐(스프레드 p90 3.09%)"로 적었다. 마트로 다시 보면:

| 마켓(10일, 체결 있는 분) | 스프레드 bp p50/p90 | 체결/깊이 p50/p90 | 분 변동폭 bp p50/p90 |
|---|---|---|---|
| KRW-BTC | 1.5 / 3.9 | 0.082 / 0.483 | 3.6 / 9.8 |
| KRW-XRP | 5.6 / 6.9 | 0.015 / 0.085 | 10.7 / 21.4 |
| KRW-LSK | 32 / 66.5 | 0.055 / 0.452 | 60.2 / 153.2 |
| KRW-EURC | 34.8 / 89.1 | 0.006 / 0.058 | 0 / 45.3 |
| 전체 | 30.5 / 83 | 0.004 / 0.063 | 0 / 64 |

분 안 변동폭 구간별로 보면 스프레드는 단조롭지 않지만(<10bp 33.2 → ≥300bp 42.8) **체결/깊이는 0.002 → 1.003 으로 500배** 오른다. 즉 큰 변동은 "스프레드가 넓어서"가 아니라 "호가 잔량 전체를 먹는 체결이 들어와서" 생긴다. EURC 알림 시간대(09-13 15:31 UTC)의 최악 분: 체결 1,440건, 체결/깊이 **5.4**, 스프레드 156bp, 변동폭 7,633bp.
→ 유동성 플래그 후보 정의: **volume_over_depth15 ≥ 1 인 분** (전체 1.53M 분 중 ≥300bp 변동 분의 중앙값이 1.003). 임계의 근거는 이 표이고, 검증은 다음 정답 라벨(거래소 지정)과의 대조로 — 2층에서.
