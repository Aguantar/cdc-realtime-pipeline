# 19. 유실 방지 구조 — 실무 대비 현황표와 작업 순서

작성 2026-09-16. 이 표가 이후 작업의 기준이다. 항목이 바뀌면 여기부터 갱신하고, "우리" 열은 **실측 근거가 있을 때만** "있음"으로 바꾼다.

원칙: 손실을 0으로 만들 수는 없다. 목표는 **어디서 얼마를 잃을 수 있는지 숫자로 알고, 잃으면 즉시 알고, 잃은 것에 계보가 남는 것**이다.

## 4. 갱신 규칙
- "우리" 열을 바꾸려면 근거 열에 실측(문서 번호·수치)이 있어야 한다.
- 새 유실 사고가 나면 표에 행을 추가하고, 기존 행의 "있음"이 틀렸다면 "있음(깨짐)"으로 바꾸고 이유를 적는다.
