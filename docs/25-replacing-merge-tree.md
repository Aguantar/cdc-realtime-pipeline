## 2. 설계
- `ReplacingMergeTree(flink_ts)`: 중복 키 = 정렬 키 (market, source_ts, trade_id). 재전송 행은 같은 binlog 이벤트라 source_ts 도 같다 → 같은 키. 버전 = flink_ts(늦게 들어온 행 유지, 내용은 동일).
- 파티션·TTL·인덱스는 그대로. Flink 싱크·dbt·대조 DAG 는 이름으로 접근하므로 변경 없음.
- **한계(알고 감)**: 중복 제거는 머지 시점에 일어난다. 머지 전 조회는 `FINAL` 을 붙이거나 중복을 허용해야 한다. 일배치(대조·규칙 평가)는 다음날 실행이라 이미 머지된 뒤다. 같은 trade_id 가 다른 source_ts 로 들어온 초기 사례 3건(202602)은 별개 키라 남는다.
