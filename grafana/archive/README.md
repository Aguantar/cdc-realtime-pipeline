# 보관 — 2026-09-20 대시보드 재편으로 내린 정의

재편 이유(docs/38 §5): 대시보드가 "어떻게 만들었나"(원본 / dbt / 운영)로 나뉘어 있어
**유입·지연·이상탐지·시장 데이터 네 갈래가 서로 겹쳤다.** 보는 사람은 "무엇에 답하나"로 찾는다.

| 파일 | 원래 대시보드 | 어디로 갔나 |
|---|---|---|
| `cdc-pipeline-quality.json` | CDC Pipeline Quality (dq_*) | 전량 → **파이프라인 관측 · 오류 탐지** (④정확성 · ⑤오류/공백), 규칙 평가만 → **이상탐지** ③ |
| `airflow-operations.json` | 파이프라인 운영 (자원·유입·알럿) | 전량 → **파이프라인 관측 · 오류 탐지** (①지금 상태 · ②유입 · ⑥자원/알럿), 마켓 상태만 → **이상탐지** ⑤ |
| `cdc-dbt-analytics.json` | CDC Crypto Analytics (DBT) | 시장·급등 패널 → **이상탐지** ②③④ |

패널은 **옮긴 것이지 다시 쓴 것이 아니다** — 검증된 SQL 을 그대로 들고 자리만 새로 줬다.
되돌리려면 이 파일들을 `grafana/provisioning/dashboards/json/` 으로 복사하고 Grafana 를 재시작한다.
